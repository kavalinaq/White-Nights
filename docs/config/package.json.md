# package.json (frontend)

## Назначение

Описывает фронтенд-проект: его зависимости (библиотеки), доступные команды и метаданные. npm (или другой менеджер пакетов) читает этот файл и устанавливает всё необходимое командой `npm install`.

## Полный разбор кода

```json
{
  "name": "frontend",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "lint": "eslint .",
    "preview": "vite preview"
  },
  "dependencies": { ... },
  "devDependencies": { ... }
}
```

### Построчный разбор

**`"private": true`**
Запрещает случайную публикацию этого пакета в реестр npm. Защита от ошибки.

**`"type": "module"`**
Говорит Node.js, что все `.js` файлы в проекте — это ES-модули (используют `import`/`export`, а не `require`/`module.exports`).

**`"scripts"`**
Команды, которые запускаются через `npm run <имя>`:
- `"dev": "vite"` — запускает dev-сервер с горячей заменой модулей
- `"build": "tsc -b && vite build"` — сначала проверяет TypeScript (`tsc -b`), затем собирает оптимизированный бандл
- `"lint": "eslint ."` — проверяет весь код на ошибки и стиль
- `"preview": "vite preview"` — локально запускает собранный бандл для проверки перед деплоем

### Зависимости (dependencies)

**`"@stomp/stompjs": "^7.3.0"`**
Клиент протокола STOMP для WebSocket. Используется в чате для отправки и получения сообщений в реальном времени.

**`"@tailwindcss/vite": "^4.2.4"` / `"tailwindcss": "^4.2.4"`**
Tailwind CSS — утилитарный CSS-фреймворк. Вместо написания CSS-файлов используются классы прямо в JSX: `className="flex gap-4 p-2"`.

**`"@tanstack/react-query": "^5.99.2"`**
TanStack Query (ранее React Query) — управление серверным состоянием: кэш данных, автоматические повторные запросы, синхронизация. Заменяет `useEffect` + `useState` для работы с API.

**`"axios": "^1.15.0"`**
HTTP-клиент. Удобнее нативного `fetch`: автоматически парсит JSON, поддерживает интерцепторы для добавления заголовков авторизации.

**`"i18next": "^26.2.0"` / `"react-i18next"` / `"i18next-browser-languagedetector"`**
Библиотека интернационализации. Позволяет хранить тексты в отдельных файлах и переключать язык интерфейса.

**`"react": "^19.2.4"` / `"react-dom": "^19.2.4"`**
React 19 — библиотека для построения UI. `react-dom` добавляет поддержку браузерного DOM.

**`"react-router-dom": "^7.14.1"`**
Маршрутизация в SPA: `/profile`, `/feed`, `/chat` и т.д. — всё без перезагрузки страницы.

**`"sockjs-client": "^1.6.1"`**
Резервный транспорт для WebSocket. Если браузер не поддерживает WebSocket — автоматически переключается на HTTP long-polling.

**`"zod": "^4.3.6"`**
Валидация данных с полной поддержкой TypeScript. Используется для проверки форм: `z.string().email().min(5)`.

**`"zustand": "^5.0.12"`**
Минималистичный менеджер глобального состояния. Хранит данные об аутентифицированном пользователе и непрочитанных сообщениях.

### DevDependencies

**`"typescript": "~6.0.2"`**
TypeScript — надмножество JavaScript с системой типов. Компилируется в JavaScript.

**`"eslint"` + плагины**
Статический анализатор кода. Находит потенциальные ошибки и нарушения стиля до запуска программы.

**`"@vitejs/plugin-react": "^6.0.1"`**
Плагин Vite для обработки React/JSX файлов.

**`"@types/*"`**
Файлы TypeScript-типов для библиотек, написанных на JavaScript (React, sockjs-client). Позволяют IDE показывать автодополнение.
