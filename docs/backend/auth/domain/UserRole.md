# UserRole

## Назначение

Перечисление (enum) ролей пользователей в системе. Определяет три уровня доступа: обычный пользователь, модератор и администратор. Роль хранится в базе данных как строка и влияет на то, какие endpoint-ы доступны пользователю.

## Полный разбор кода

```java
package com.whitenights.auth.domain;

public enum UserRole {
    user, moderator, admin
}
```

### Построчный разбор

**`public enum UserRole`**
`enum` (enumeration — перечисление) — специальный тип Java, у которого фиксированный набор значений. В отличие от строки или числа, компилятор гарантирует, что роль может быть только одним из трёх значений — нельзя случайно написать `"useer"` или `4`.

**`user, moderator, admin`**
Три константы enum. По соглашению Java константы пишутся в UPPER_CASE, но здесь использован lower_case намеренно — это значения, которые хранятся в БД как строки (`"user"`, `"moderator"`, `"admin"`), и они должны совпадать со значениями в существующих данных.

**Как используется:**
В классе `User` поле `role` аннотировано `@Enumerated(EnumType.STRING)` — Hibernate сохраняет `UserRole.admin` как строку `"admin"` в столбце `role` таблицы `users`.

В `SecurityConfig` роли используются для ограничения доступа:
```java
.requestMatchers("/api/admin/**").hasRole("admin")
```
