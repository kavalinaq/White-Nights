# ResetPassword

## Назначение

DTO для второго шага сброса пароля: пользователь передаёт токен из письма и новый пароль. Токен подтверждает, что запрос на сброс был сделан с доступом к почте.

## Полный разбор кода

```java
public record ResetPassword(
    @NotBlank String token,
    @NotBlank @Size(min = 8) String newPassword
) {}
```

### Построчный разбор

**`@NotBlank String token`**
UUID из письма. `AuthService.resetPassword()` ищет его в таблице `password_reset_tokens`, проверяет срок действия и, если всё в порядке, обновляет пароль.

**`@Size(min = 8) String newPassword`**
Те же требования к новому паролю, что и при регистрации.

**После успешного сброса:** `AuthService` удаляет все refresh-токены пользователя — аннулирует все активные сессии. Это важно для безопасности: если кто-то взломал почту и сбросил пароль, все существующие сессии должны завершиться.
