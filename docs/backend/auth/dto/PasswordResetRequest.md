# PasswordResetRequest

## Назначение

DTO для запроса начала процедуры сброса пароля. Содержит только email — на него будет отправлено письмо с токеном сброса.

## Полный разбор кода

```java
public record PasswordResetRequest(
    @NotBlank @Email String email
) {}
```

### Построчный разбор

**Почему только email?**
Это первый шаг двухэтапного сброса пароля. Пользователь сначала называет свой email, получает письмо, а затем использует `ResetPassword` DTO для второго шага — ввода нового пароля с токеном из письма.

**Безопасность:** `AuthService.requestPasswordReset()` намеренно не сообщает, существует ли пользователь с таким email — это предотвращает перебор аккаунтов (user enumeration attack). Но текущая реализация выбрасывает `NotFoundException`, если пользователь не найден — это стоит иметь в виду.
