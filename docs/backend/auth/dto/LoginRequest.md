# LoginRequest

## Назначение

DTO для запроса входа в систему. Содержит email и пароль пользователя. Аннотации Bean Validation автоматически проверяют данные до передачи в сервис.

## Полный разбор кода

```java
public record LoginRequest(
    @NotBlank @Email String email,
    @NotBlank String password
) {}
```

### Построчный разбор

**`@NotBlank`**
Проверяет, что строка не `null`, не пустая (`""`) и не состоит только из пробелов (`"   "`). Если проверка провалится — Spring вернёт HTTP 400 с описанием ошибки, до вызова метода сервиса дело не дойдёт.

**`@Email`**
Проверяет формат email через регулярное выражение: должны быть символ `@` и домен. Не проверяет существование почтового ящика — только формат.

**`String password`**
Пароль не проверяется по `@Size` при входе — только `@NotBlank`. Это потому, что нужно поддерживать старых пользователей с паролями длиной менее 8 символов (требование по длине только при регистрации).
