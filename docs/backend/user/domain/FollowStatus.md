# FollowStatus

## Назначение

Перечисление статусов подписки. `pending` — заявка на подписку к приватному аккаунту (ещё не одобрена). `accepted` — активная подписка.

## Полный разбор кода

```java
public enum FollowStatus {
    accepted, pending
}
```

**`accepted`** — подписка активна. Подписчик видит посты автора. Создаётся при подписке на **публичный** аккаунт, или когда владелец **приватного** аккаунта одобрил заявку.

**`pending`** — заявка на подписку. Создаётся при подписке на **приватный** аккаунт. Подписчик ещё не видит посты. Владелец видит заявку в `/me/follow-requests` и может принять (`accepted`) или отклонить (удалить запись).
